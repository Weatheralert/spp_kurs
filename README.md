# 🎬 Movie Recommender на графовой БД (Neo4j)

Курсовой проект по дисциплине «Современные платформы программирования».

Рекомендательный сервис фильмов, построенный на графовой базе данных **Neo4j**.
Система использует коллаборативную фильтрацию и графовые алгоритмы
(**Jaccard similarity**, **Personalized PageRank**) для формирования
персональных рекомендаций и их объяснения.

---

## 📌 О проекте

**Цель работы** — разработать рекомендательный сервис фильмов на основе
графовой СУБД и оценить качество графовых алгоритмов рекомендаций
по сравнению с базовыми подходами.

**Задачи:**

1. Спроектировать графовую модель данных для домена «фильмы»
   (пользователи, фильмы, жанры, персоны).
2. Загрузить и подготовить датасет MovieLens для хранения в графовой БД.
3. Реализовать алгоритмы рекомендаций:
   - коллаборативная фильтрация на общих соседях (User-Based CF);
   - сходство пользователей/фильмов по Jaccard (Node Similarity);
   - персонализированный PageRank (Personalized PageRank).
4. Оценить качество рекомендаций по метрикам Precision@K, Recall@K, NDCG@K.
5. Сравнить результаты алгоритмов и сформулировать выводы.

**Актуальность:** графовые БД естественно моделируют отношения
«пользователь — фильм — жанр — персона», а обход связей в них
эффективнее, чем JOIN-ы в реляционных СУБД, что критично для
рекомендательных систем.

## 🕸️ Концептуальная модель данных

Узлы:

- `User` — свойства: `userId`
- `Movie` — свойства: `movieId`, `title`, `year`
- `Genre` — свойства: `name`
- `Person` — свойства: `name`, `role` (`actor` / `director`)

Связи:

- `(:User)-[:RATED {rating, timestamp}]->(:Movie)`
- `(:Movie)-[:HAS_GENRE]->(:Genre)`
- `(:Person)-[:ACTED_IN]->(:Movie)`
- `(:Person)-[:DIRECTED]->(:Movie)`

## 🧠 Алгоритмы рекомендаций

### 1. User-Based Collaborative Filtering
Рекомендуем фильмы, высоко оценённые пользователями со схожим
вкусом, исключая уже просмотренные целевым пользователем.

### 2. Node Similarity (Jaccard)
Вычисляет схожесть пользователей по множеству общих фильмов,
затем рекомендации строятся по «похожим» пользователям.

### 3. Personalized PageRank
Случайное блуждание по графу с возвратом к целевому пользователю.
Фильмы с наибольшим весом PageRank относительно целевого узла
получают более высокий ранг — это даёт неочевидные, но релевантные
рекомендации.

## 📈 Оценка качества

Используемые метрики:

- **Precision@K** — доля релевантных рекомендаций среди первых K.
- **Recall@K** — доля найденных релевантных фильмов среди всех релевантных.
- **NDCG@K** — качество ранжирования с учётом позиции рекомендации.

Протокол оценки:

1. Разбиение датасета на train/test (например, 80/20 по времени).
2. Генерация Top-K рекомендаций для каждого тестового пользователя.
3. Расчёт метрик и сравнение алгоритмов.

> Результаты экспериментов будут добавлены после реализации.
